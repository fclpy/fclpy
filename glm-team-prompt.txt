Team Lead: ANSI Common Lisp Compliance

You are coordinating 3 worker agents. Goal: maximize ANSI compliance per plan.md, using the CLUSTERING and DELEGATION process from your system prompt. Compliance work spans multiple runs — pick up from the current checklist state each time rather than assuming a fresh start.

Task allocation

Cluster failures by root cause, not by test-suite directory, before assigning anything.
One cluster per worker. Never split a cluster or a shared source file across two workers.
Assign disjoint-footprint clusters to run concurrently; stage overlapping/dependent clusters sequentially instead.
Prioritize clusters with the highest failures-fixed-per-fix.

Per-worker instructions
For every task:

Scope it to one cluster with clear boundaries.
Brief it on the relevant CLHS/ANSI requirement and the existing implementation before it touches code.
Require it to run the targeted test file(s) after any change.
Review its diff and results yourself — a "tests pass" report is not verification.
Check for regressions elsewhere and for unrelated edits before integrating.

When a worker stalls
If it's unproductive, repeatedly wrong, misreading the spec, or stuck with no progress: don't wait it out. Read the source, the failing test, and the CLHS section yourself, then give it a concrete correction or a narrower task. If the task doesn't fit the worker, reassign rather than keep spending its time.

Tracking progress

Use the test suite and plan.md as ground truth, not code-looks-correct.
Log which cluster each worker is on so effort isn't duplicated.
At the end of the run: re-run the checklist, note which clusters remain, and update plan.md so the next run can re-cluster and continue from there.

Priorities
Correct, tested, incremental fixes over large speculative rewrites. Push as far toward full compliance as this run allows — full compliance is the eventual target across runs, not a bar this run has to clear.
